# 📐 Middle Math Lab (중학교 수학 인터랙티브 교보재 실험실)

> 중학교 수학 수업에서 교사와 학생이 웹 브라우저로 직접 조작하고 관찰하며 수학적 원리를 발견할 수 있는 인터랙티브 디지털 교보재 저장소입니다.

[![Vercel Deployment](https://img.shields.io/badge/Vercel-Deployed-black?logo=vercel)](https://vercel.com)
[![GitHub license](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

---

## 🎯 프로젝트 목적
- **개념의 시각화**: 공식 암기가 아닌 직접적인 조작(Manipulatives) 활동을 통해 개념을 직관적으로 이해합니다.
- **무설치 웹 구동**: PC, 태블릿(iPad, 갤럭시 탭), 스마트폰 등 모든 환경에서 별도 프로그램 설치 없이 브라우저 링크 하나로 접속합니다.
- **수업 최적화**: 학교 전자칠판 또는 학생 1인 1디바이스 수업에서 즉시 활용할 수 있도록 설계되었습니다.

---

## 📚 교보재 목록

### 1. [중2-2 기하] 종이접기로 내심 찾고 내접원 그리기 (`incenter.html`)
- **주요 내용**:
  - 삼각형의 두 변을 겹쳐 접으며 각의 이등분선의 성질 탐구
  - 세 각의 이등분선이 한 점(내심 $I$)에서 만남을 확인
  - 내심에서 세 변에 수선의 발을 내려 거리가 같음을 관찰
  - 컴퍼스로 내접원을 그리고 예각·직각·둔각삼각형에서의 위치 비교

### 2. 향후 추가 예정 교보재 (Roadmap)
- [ ] [중1-2] 정다면체 3D 전개도 접고 펼치기
- [ ] [중2-2] 세 변의 수직이등분선과 삼각형의 외심
- [ ] [중2-2] 삼각형의 중선과 무게중심의 2:1 성질
- [ ] [중2-2] 피타고라스 정리 시각적 퍼즐 증명
- [ ] [중3-2] 원주각과 중심각의 관계 및 성질
